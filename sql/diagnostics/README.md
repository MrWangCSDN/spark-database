# 配置导入与预检诊断

这两份脚本只执行 SELECT，应连接到 bd 服务实际使用的元数据库和 schema 后运行。

- `check_bcomp_configuration_completeness.sql`：检查配置、两侧 SQL、字段及连接引用的完整性，并返回具体缺项。默认查询编号478～498，包含正常与异常对照；可按实际情况修改 WHERE 范围。
- `check_bcomp_field_import_completeness.sql`：统计总字段数、各配置字段数/位置范围/核对键数，并查询编号478～498的字段明细。总字段数为500的倍数仅提供批次中断线索，完整性应以同一版本的原始 Axon 脚本为准。

脚本不输出密码、密文、连接URL、用户名或业务查询SQL正文。字段明细脚本会显示字段名称及顺序。补齐数据前，应核对原始脚本中的字段选择、忽略规则和核对键；预检通过只代表满足基础条件，不能证明字段清单与原始脚本完全一致。

已在隔离H2的完整数据、字段批次缺失和恢复数据中验证。SQL采用GaussDB/MySQL通用查询语法；未在现场数据库执行。页面预检直接读取元库，修正数据后重新预检即可。
