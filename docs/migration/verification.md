# 迁移验证记录（2026-09-20）

环境：JDK 17.0.12、Maven 3.9、Spark 3.5.3 local[2]、H2测试库。生产元数据库和业务库均未连接。

## 已验证

- 服务模块18项测试：库表类型过滤、两个线程条件领取、歧义任务跳过、失败回写、21位置参数、原AES协议、旧frw属性、原主类列表、结果完整性、刷新成功/失败/超时、在途任务后继续领取、停机中断与停止领取、原HTTP接口、无文件/Redis依赖的完整Boot启动。
- Spark模块2项测试：参数不完整时在启动Spark前拒绝；通过原main创建SparkSession并执行原Kryo、JDBC读取、cogroup、批量入库路径，小数据包含相同/差异/缺行/重复键。
- 原Spark源码SHA-256校验；从SparkRun开始直至文件结束的业务代码与来源逐字一致。Git归档统一换行符，逻辑不变。
- 可执行发布包从临时独立目录启动，使用外置H2驱动与测试表；GET运行状态返回2，POST刷新返回业务码200；SIGTERM正常关闭。
- 服务包不含Spark Core/SQL及作业类，作业包不含Boot嵌套布局；测试建表脚本不在发布包中。

## 尚未验证
